# STACK & HEAP

## Diagram 1 — After Line 1

```text
Line 1:
Order o1 = new Order { OrderId = 1, CustomerName = "Ali" };

+----------------------- STACK -----------------------+
|                                                     |
|  o1                                                 |
|  +---------+                                        |
|  | 0x1000  | --------------------+                  |
|  +---------+                     |                  |
|                                                     |
+-----------------------------------------------------+

+------------------------ HEAP -----------------------+
|                                                     |
|  Address: 0x1000                                    |
|  +-----------------------------------------------+  |
|  | Order Object                                  |  |
|  |-----------------------------------------------|  |
|  | OrderId      = 1                              |  |
|  | CustomerName = "Ali"                          |  |
|  | IsPaid       = false                          |  |
|  +-----------------------------------------------+  |
|                                                     |
+-----------------------------------------------------+
```

After line 1, `o1` stores a reference to the `Order` object located at address `0x1000` on the heap.

## What would be different with structs?

If `Order` were a `struct` instead of a `class`, it would be a value type. When we write `Point p2 = p1;`, the values of `p1` are copied into `p2`.

For example:

```text
+----------------------- STACK -----------------------+
|                                                     |
|  p1                    p2                           |
|  +-----------+         +-----------+                |
|  | X = 1     |         | X = 1     |                |
|  | Y = 2     |         | Y = 2     |                |
|  +-----------+         +-----------+                |
|                                                     |
+-----------------------------------------------------+

p2.X = 10;

+----------------------- STACK -----------------------+
|                                                     |
|  p1                    p2                           |
|  +-----------+         +-----------+                |
|  | X = 1     |         | X = 10    |                |
|  | Y = 2     |         | Y = 2     |                |
|  +-----------+         +-----------+                |
|                                                     |
+-----------------------------------------------------+
```

Unlike a class reference, copying a struct creates an independent copy of its values. Therefore, changing `p2` does not change `p1`.
